Mikadodo V7 — logique Stock pour Recettes faisables/réalisables

Un ingrédient compte comme disponible depuis le stock uniquement s’il a été explicitement catégorisé « Stock » dans le lien de l’ingrédient (stockPotential), puis s’il est trouvé dans le stock physique.

La pastille bleue et le texte de localisation « X ingrédient(s) dans le réfrigérateur/congélateur/placard » sont conservés. Les ingrédients sans catégorie Stock ne sont plus considérés automatiquement comme présents dans le stock.

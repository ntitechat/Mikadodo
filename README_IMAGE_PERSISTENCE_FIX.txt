CORRECTION : IMAGES PERSISTANTES
================================

Les images générées par « Enregistrer l’image » sont maintenant copiées dans
IndexedDB de l’application avant le téléchargement du fichier PNG.

Au prochain lancement, la section « 🖼️ Images enregistrées » recharge ces
images automatiquement.

Un bouton « Importer une image » permet aussi d’ajouter à l’application les
anciens fichiers PNG/JPG déjà téléchargés avant cette correction.

Les fichiers téléchargés restent également disponibles dans le dossier de
téléchargement normal du navigateur.
